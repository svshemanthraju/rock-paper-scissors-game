# Rock Paper Scissors Game 🪨📄✂️

A beginner-friendly Rock Paper Scissors game built using Python.

## About

Play Rock Paper Scissors against the computer. The computer randomly selects rock, paper, or scissors, and the winner is decided using conditional statements.

## Concepts Used

- Python basics
- `random` module
- User input
- Conditional statements (`if`, `elif`, `else`)
- String methods

## How to Run

1. Make sure Python is installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/svshemanthraju/rock-paper-scissors-game.git
   ```
3. Open the project folder in your terminal.
4. Run:
   ```bash
   python rock_paper_scissors.py
   ```

## Features

- Random computer selection
- User input
- Win, lose, and draw detection
- Invalid input handling
- Ignores extra spaces and letter casing in the user's choice
